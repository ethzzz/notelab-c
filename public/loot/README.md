# 摸金行动 · 物品图片

放这里的图片会出现在 B 端「摸金行动 → 物品配置」的**图片下拉**里。

- 支持 `png / jpg / jpeg / webp / gif / svg / avif`；
- 子目录最多 2 层（后端遍历深度上限 3），跳过点开头的隐藏文件；
- 清单由后端 `GET /api/loot-assets` **扫盘下发**（B 端浏览器读不到 C 端仓库），
  加图后刷新后台页面即可，不用改任何代码；
- 目录不存在时接口返回 `available:false`，B 端静默退回 emoji，不会报错。

存放的值就是浏览器可直接访问的 URL：`/loot/<相对路径>`（如 `/loot/gold.png`）。
